
# 🎾 Tennis Performance Analysis

Proyecto personal de **análisis del rendimiento de jugadores profesionales de tenis** a partir de datos históricos de partidos ATP.

## 🎯 Objetivo

Desarrollar un **sistema de puntuación** que permita comparar el rendimiento de los jugadores teniendo en cuenta:

- **Categoría del torneo** (Grand Slam, Masters 1000, ATP 500, ATP 250...).
- **Ronda alcanzada** (final, semifinal, cuartos...).
- **Resultado del partido** (victoria o derrota).

## 🛠️ Tecnologías

- **Python**
- **pandas y NumPy** — Procesamiento y análisis de datos.
- **Matplotlib** — Visualización de datos.
- **Git y GitHub** — Control de versiones.

## 📊 Datos

Se utilizan datos históricos de partidos ATP, comenzando por la **temporada 2024**.
